# ZXIC-UI-Viewer
ZXIC-UI-Viewer是一款ZXIC芯片随身Wifi设备WebUi的本地预览工具。本工具旨在方便新手玩家快速了解/熟悉自己更改的 Web UI 样式。
# ZXIC-UI-Viewer

中兴微(ZXIC)芯片随身WiFi 后台界面本地查看器，**无需连接真实设备，也无需安装 Python**。
把从设备/固件里提取出来的 web 网页文件放进本文件夹，双击启动即可在浏览器查看后台。

## 工作原理

设备后台就是一组网页文件（index.html + css/js/subpg 等），请求后端接口 `/goform/*` 返回数据。
本工具在本地起一个 HTTP 服务：

- 静态网页文件 → 直接读取本地文件返回（就是你放进来的那套 web）
- `/goform/*` 接口 → 返回模拟数据（任意密码登录、设备在线）
- 页面在浏览器里能完整打开、能登录、能点各个菜单

## 使用方法（三步）

### 方式一：选择 web 文件夹（推荐，不用复制文件）

1. **双击** `选择web文件夹.bat`
2. 弹出窗口中选择你从设备提取的 web 文件夹（内含 index.html 的那层），点确定
3. 自动启动服务并打开浏览器 `http://127.0.0.1:8123/index.html`，登录页输入**任意密码**即可进入

> 选中的文件夹**不会被复制/改动**，工具直接读取该位置，可以随时换不同的 web 文件夹。

### 方式二：手动放文件（把 web 放进本文件夹）

1. **提取 web 文件**：从你的设备（或固件）里把后台网页文件提取出来
   - 提取结果是 `index.html`、`css\`、`js\`、`subpg\`、`i18n\`、`pic\` 这些
2. **导入 web 文件**：把提取出的全部文件放进本文件夹
   - 平铺：直接放在本文件夹根目录（和 mock_server.exe 同级）
   - 或子目录：全部放进本文件夹下的 `web\` 子目录（二选一即可）
   - 注意：每次只放**一套** web，导入新设备前先清掉旧的（见下方提示）
3. **双击** `启动后台.bat`，浏览器自动打开 `http://127.0.0.1:8123/index.html`
   - 登录页输入**任意密码**即可进入

> 换 web 时建议先把本文件夹里原来的网页文件清掉（css/js/pic/subpg/i18n 和 index.html），
> 再放入你要查看的那套，避免新旧文件混在一起导致页面错乱。

## 常见问题

**Q：打开后没有登录框 / 页面空白？**
A：说明你没导入 web 文件，或文件不完整、index.html 缺失。确认 index.html 在本文件夹根目录（或 web\ 子目录）。

**Q：登录后某个菜单打不开？**
A：该菜单页面对应的 subpg 模板或 js 文件缺失。中兴微方案各型号菜单不完全一样，缺哪个页面就把哪个文件从设备里补提取出来。

**Q：端口被占用？**
A：启动脚本会自动检测，若 8123 被占用会直接打开浏览器；也可关掉占用 8123 的程序再启动。

**Q：页面上的状态数据（信号/流量等）为什么是假的？**
A：本工具是纯本地模拟，不连设备，所有 /goform/ 数据都是模拟值，仅供查看界面用。

**Q：改了网页文件但浏览器还是显示旧内容？**
A：本工具服务端已强制禁用缓存（Cache-Control: no-cache, no-store），启动脚本打开浏览器时也会带随机参数强制刷新。若仍显示旧页，按 `Ctrl+F5` 强制刷新即可。

## 注意事项

- 本工具只做本地界面查看，不会向任何真实设备发送指令，也不会修改设备配置
- 不支持真实设备的联网状态显示（那需要连设备读取）
- 真实固件刷写请用专业刷机工具，本工具不涉及刷机
